A small, dependency-free Python program that writes one short poem about permission — the power to ask, and to be given — to `entry.txt`. The poem is fixed and deterministic: every run produces exactly the same text (197 Unicode characters, plain UTF-8, no network access). Output goes to `MAKEFUN_OUTPUT_DIR` when set, falling back to `/output`; the program creates that directory if needed and never removes it.

## Run it

```sh
python3 main.py
```
